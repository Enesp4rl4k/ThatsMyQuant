## 🎯 Priority UI Additions

### P0 — Alpha Portfolio Tab (IMPLEMENT NOW)
**Why:** Surfaces this session's biggest win (Sharpe 3.87 validated portfolio). Without UI, the user can only see it via CLI output.

**Contents:**
- Validated portfolio table: symbol, type, weight, trades, WR, Sharpe, PnL, PF per position
- Aggregate KPI cards: Portfolio Sharpe, Max DD, Total PnL, Correlation avg
- Correlation heatmap (NxN)
- Equity curve chart
- Actions: **"Run Backtest"** → calls PortfolioBacktestRunner, **"Launch Paper Trade"** → wires to PaperTradingService with the 4-position config

### P1 — Funding Monitor Widget (Terminal tab or new tab)
**Why:** Live actionable edge data. User needs to see funding rates in real-time to trust the bot.

**Contents:**
- Per-symbol current funding rate
- Color-coded by threshold (green if below entry, yellow if near, red if signal fired)
- 24h funding history mini-chart
- "Signal Fired" notification when threshold crossed

### P2 — Pairs Discovery Tab
**Why:** Systematic pair hunting. Currently must run CLI manually.

**Contents:**
- Symbol basket input (multi-select)
- "Scan Cointegration" button
- Results table: pair, half-life, cointegration strength, Hurst, correlation, quality score
- Sortable, filterable
- "Promote to Portfolio" → adds selected pair to Alpha Portfolio

### P3 — Correlation Heatmap (reusable control)
**Why:** Visual tool for diversification assessment. Used in Alpha Portfolio + standalone.

**Contents:**
- SciChart-based heatmap
- Color gradient: -1 (red) → 0 (neutral) → +1 (green)
- Labels for strategy names
- Tooltip with exact values

### P4 — Champion/Challenger Arena
**Why:** Shadow-strategy visibility. Currently ChampionChallengerService runs invisibly.

**Contents:**
- Active champion strategy panel
- Active challengers (shadow mode) list
- Paired t-stat display
- Promotion decision button

### P5 — MC Bootstrap Visualization
**Why:** MC reports exist but no histogram/distribution view.

**Contents:**
- Sharpe distribution histogram (1000-sample bootstrap)
- 5th/50th/95th percentile markers
- P(loss) probability gauge
- Tail risk visualization

## Implementation Order

**Today (this session):** P0 — Alpha Portfolio Tab
**Next session:** P1 + P3 (Funding Monitor + Correlation Heatmap)
**Later:** P2, P4, P5 based on priority

## Design System Consistency

Follow existing patterns:
- `TerminalCardStyle` for card borders
- `Accent` brush for CTAs
- `BuyColor` / `SellColor` for green/red
- `MonoFont` for numeric values
- `TextMain` / `TextSoft` / `TextMuted` typography hierarchy
- `BoolToVis` converter for show/hide
- `[ObservableProperty]` and `[RelayCommand]` from CommunityToolkit.Mvvm
